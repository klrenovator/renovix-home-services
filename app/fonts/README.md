# Fonts

## Plus Jakarta Sans (`plus-jakarta-sans-latin-*-normal.woff2`)

The site's brand typeface, loaded through `next/font/local` in
`app/[lang]/layout.tsx`. Plus Jakarta Sans by Tokotype is licensed under the
SIL Open Font License 1.1 — https://github.com/tokotype/PlusJakartaSans

## Open Graph card fonts (`*-og.ttf`)

Used only by the social-card route `app/[lang]/opengraph-image.tsx`, which
needs TTF data (satori's opentype.js cannot read woff2) covering both Latin
and the Chinese card text without any build-time network request:

- `plus-jakarta-sans-latin-{400,700,800}-og.ttf` — the brand font above,
  converted from the woff2 files with `fonttools` (`woff2.decompress`).
- `noto-sans-sc-og-{400,700}.ttf` — Noto Sans SC (SIL Open Font License 1.1,
  https://github.com/notofonts/noto-cjk), subsetted to the characters the OG
  card can render.

Both are regenerated by `scripts/make-og-fonts.py`; their glyph coverage of
the live dictionaries is verified by `npm run audit:og-fonts`. The OG route
registers them under the family names "Plus Jakarta Sans" and
"Noto Sans SC" and renders with the CSS-style stack
`"Plus Jakarta Sans, Noto Sans SC"` — per-glyph fallback picks the brand face
for Latin and Noto for hanzi.
